# 100-guesstimate-questions

`index.html` — the PM Guesstimate Vault, a static single-page practice tool for 100 product-management guesstimate/estimation interview questions.

## cognitive-training-app/

A separate, self-contained project in this repo: **NeuroLap**, a daily brain-training mobile app (React Native + Expo/TypeScript) with memory, logic, focus, and reasoning exercises, adaptive difficulty, streak tracking, and a local SQLite progress history. See [`cognitive-training-app/README.md`](cognitive-training-app/README.md) for the quickstart and [`cognitive-training-app/docs/`](cognitive-training-app/docs/) for the full architecture, database schema, exercise mechanics, wireframes, and roadmap.
